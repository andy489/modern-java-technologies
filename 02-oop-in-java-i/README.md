# OOP in Java — Part I

## Topics

- Object-oriented programming fundamentals — objects and classes
- Class methods, varargs, static fields and methods
- The `this` keyword
- Packages and access modifiers (`public`, `protected`, `private`, package-private)
- Encapsulation
- Inheritance — `extends`, method overriding, `super`
- The Java class hierarchy — `java.lang.Object`, `equals()`, `hashCode()`
- The `instanceof` operator and pattern matching for `instanceof` (Java 16+)
- The `final` keyword
- Polymorphism — runtime (method overriding) and compile-time (overloading)
- Abstract classes
- Interfaces — default methods (Java 8+), static methods, private methods (Java 9+)
- Abstraction
- Records (Java 16+)
