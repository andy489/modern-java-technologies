# Generics

## Topics

- The need for generics — type safety without casting
- Generic classes and interfaces
- Type parameter naming conventions (`T`, `E`, `K`, `V`, `R`, …)
- Generic methods — declaration and invocation
- Covariance, contravariance, and invariance
- Generic types and inheritance — why `List<Dog>` is not a `List<Animal>`
- Bounded type parameters — `extends`
- Wildcards — upper-bounded (`? extends T`), lower-bounded (`? super T`), unbounded (`?`)
- The Get & Put principle (PECS)
- Generics vs. C++ templates
- Type erasure — how the compiler handles generics at runtime
- Raw types and type compatibility
- Prefer `List` over arrays for generic code
- Restrictions on generic classes and interfaces
