# Introduction to Java

## Topics

- What is Java? — language, compiler, JVM, JDK, platform
- Java editions (SE, EE, ME, Card)
- JDK tools: `javac`, `java`, `jshell`, `javadoc`, `jar`
- Popular IDEs: IntelliJ IDEA, Eclipse, NetBeans
- Data types and variables — primitive types, wrapper types, autoboxing
- Type conversions and operator precedence
- Strings — string pool, comparison, mutation, text blocks
- Local variable type inference (`var`)
- `final` variables and constants
- Control flow — `if/else`, ternary, `while`, `do-while`, `for`
- `switch` expressions (Java 15+), pattern matching (Java 17 preview)
- Arrays — declaration, initialisation, multidimensional, operations
- Functions — declaration, parameters, return types
- Standard input and output
