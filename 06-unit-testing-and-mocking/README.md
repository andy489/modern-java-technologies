# Unit Testing & Mocking

## Topics

### Testing Fundamentals
- Why test? When to test?
- Testing as a continuous process, not a phase
- Types of tests — unit, integration, system, regression, performance
- Unit testing — characteristics, scope, definitions (SUT, fixture, assertion)

### JUnit 5
- Why use a testing framework?
- Writing a JUnit test — naming conventions, `@Test`
- `Assertions` class — `assertEquals`, `assertThrows`, `assertAll`, `assertTimeout`, …
- Lifecycle annotations — `@BeforeEach`, `@AfterEach`, `@BeforeAll`, `@AfterAll`
- Test execution order
- Advanced features — parameterised tests, `@Nested`, `@DisplayName`
- Code coverage tools

### Stubs and Mocks
- Testing classes with dependencies
- Stubs — manual test doubles, lifecycle, characteristics
- Mocks — mock objects, when to mock vs. not to mock
- Mockito — `mock()`, `verify()`, `when()`, argument matchers, `@Mock`
